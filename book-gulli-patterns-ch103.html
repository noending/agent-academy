"Appendix D - Building an Agent with AgentSpace AgentSpace is a platform designed to facilitate an "agent-driven enterprise" by integrating artificial intelligence into daily workflows. At its core, it provides a unified search capability across an organization's entire digital footprint, including documents, emails, and databases. This system utilizes advanced AI models, like Google's Gemini, to comprehend and synthesize information from these varied sources. The platform enables the creation and deployment of specialized AI "agents" that can perform complex tasks and automate processes. These agents are not merely chatbots; they can reason, plan, and execute multi-step actions autonomously. For instance, an agent could research a topic, compile a report with citations, and even generate an audio summary. To achieve this, AgentSpace constructs an enterprise knowledge graph, mapping the relationships between people, documents, and data. This allows the AI to understand context and deliver more relevant and personalized results. The platform also includes a no-code interface called Agent Designer for creating custom agents without requiring deep technical expertise."
附录 D - 使用 AgentSpace 构建 Agent（智能体） AgentSpace 是一个旨在通过将人工智能集成到日常工作流中来促进“智能体驱动的企业”的平台。其核心是提供跨组织整个数字足迹（包括文档、电子邮件和数据库）的统一搜索能力。该系统利用先进的 AI 模型（如 Google 的 Gemini）来理解和综合来自这些多样化来源的信息。 该平台支持创建和部署可执行复杂任务并自动化流程的专用 AI“智能体”。这些智能体不仅仅是聊天机器人；它们能够自主推理、规划并执行多步操作。例如，一个智能体可以研究某个主题、编制带引用的报告，甚至生成音频摘要。 为实现这一目标，AgentSpace 构建企业知识图谱，映射人员、文档和数据之间的关系。这使 AI 能够理解上下文并提供更相关、更个性化的结果。该平台还包括一个名为 Agent Designer 的无代码界面，用于创建自定义智能体，无需深厚的技术专业知识。
导读注:介绍 AgentSpace 如何以知识图谱与无代码设计器支撑自主多步智能体。
"Furthermore, AgentSpace supports a multi-agent system where different AI agents can communicate and collaborate through an open protocol known as the Agent2Agent (A2A) Protocol. This interoperability allows for more complex and orchestrated workflows. Security is a foundational component, with features like role-based access controls and data encryption to protect sensitive enterprise information. Ultimately, AgentSpace aims to enhance productivity and decision-making by embedding intelligent, autonomous systems directly into an organization's operational fabric. Figure 1 illustrates how to access AgentSpace by selecting AI Applications from the Google Cloud Console. Fig. 1: How to use Google Cloud Console to access AgentSpace Your agent can be connected to various services, including Calendar, Google Mail, Workaday, Jira, Outlook, and Service Now (see Fig. 2). Fig. 2: Integrate with diverse services, including Google and third-party platforms. The Agent can then utilize its own prompt, chosen from a gallery of pre-made prompts provided by Google, as illustrated in Fig. 3."
此外，AgentSpace 支持多智能体系统（multi-agent system），不同的 AI 智能体可通过名为 Agent2Agent（A2A）Protocol 的开放协议进行通信与协作。这种互操作性支持更复杂、可编排的工作流。安全是基础性组件，具备基于角色的访问控制（role-based access controls）和数据加密等功能，以保护敏感的企业信息。最终，AgentSpace 旨在通过将智能、自主的系统直接嵌入组织的运营架构中，来提升生产力与决策能力。 图 1 展示了如何通过从 Google Cloud Console 中选择 AI Applications 来访问 AgentSpace。 图 1：如何使用 Google Cloud Console 访问 AgentSpace 你的智能体可连接到多种服务，包括 Calendar、Google Mail、Workaday、Jira、Outlook 和 Service Now（见图 2）。 图 2：与包括 Google 及第三方平台在内的多种服务集成。 随后，智能体可使用其自己的 prompt，从 Google 提供的预制 prompt 库中选择，如图 3 所示。
导读注:A2A 协议实现多智能体互通，安全与集成能力是 AgentSpace 落地企业场景的关键。
"Fig.3: Google's Gallery of Pre-assembled prompts In alternative you can create your own prompt as in Fig.4, which will be then used by your agent AgentSpace offers a number of advanced features such as integration with datastores to store your own data, integration with Google Knowledge Graph or with your private Knowledge Graph, Web interface for exposing your agent to the Web, and Analytics to monitor usage, and more (see Fig. 5) Upon completion, the AgentSpace chat interface (Fig. 6) will be accessible. Fig. 6: The AgentSpace User Interface for initiating a chat with your Agent. In conclusion, AgentSpace provides a functional framework for developing and deploying AI agents within an organization's existing digital infrastructure. The system's architecture links complex backend processes, such as autonomous reasoning and enterprise knowledge graph mapping, to a graphical user interface for agent construction. Through this interface, users can configure agents by integrating various data services and defining their operational parameters via prompts, resulting in customized, context-aware automated systems."
图3：Google 的预组装 prompt 库（Gallery of Pre-assembled prompts） 或者，你也可以像图4那样创建自己的 prompt，随后由你的 agent 使用。 AgentSpace 提供多项高级功能，例如与数据存储（datastore）集成以存储你自己的数据、与 Google 知识图谱（Knowledge Graph）或你的私有知识图谱集成、用于将 agent 暴露到 Web 的 Web 界面，以及用于监控使用情况的分析（Analytics）等（见图5）。 完成后，即可访问 AgentSpace 聊天界面（图6）。 图6：用于发起与你的 Agent 对话的 AgentSpace 用户界面。 总之，AgentSpace 提供了一个功能性框架，用于在组织现有的数字基础设施内开发和部署 AI agent。该系统架构将复杂的后端流程（如自主推理和企业知识图谱映射）与用于构建 agent 的图形用户界面连接起来。通过该界面，用户可以通过集成各种数据服务并借助 prompt 定义其运行参数来配置 agent，从而得到定制的、具备上下文感知能力的自动化系统。
