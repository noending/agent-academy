学习路径

四个部分循序渐进，每个概念都遵循 直觉 → 定义 → 代码 → 动手实验 → 自测 → 练习 的节奏。 第一部分结束你就会有一个真正能跑的智能体；之后的每一章都在给它加一层真实世界所需的能力。

Agent 基础认知

什么是智能体？LLM 大脑 + 工具 + 循环 + 记忆四要素；Chatbot / Workflow / Agent 的判定标准；Agent Loop 与 ReAct 范式；Function Calling 的工作直觉；主流 Agent 产品生态全景。📜 论文：ReAct / CoT。

⏱ 1.5 小时零代码含实验：Agent Loop 模拟器

动手写第一个 Agent（DeepSeek 实战）

接入 DeepSeek API；裸 HTTP 请求拆解；Function Calling 完整消息流；90 行极简智能体；流式输出、超时重试、错误兜底——从「能跑」到「不脆」。

⏱ 3 小时Python / Node.js含实验：消息数组可视化

Prompt 工程与上下文设计

系统提示的解剖学；少样本示例；结构化输出与「生成→校验→重试」闭环；参数的工程含义；LLM 在链路中的五种角色；提示词的迭代方法。提示词是你写下的第一段 harness 代码。📜 论文：CoT / ReAct / Toolformer。

⏱ 2 小时含实验：提示词 A/B 对比器

知识库与 RAG 全链路

知识在链路中的位置与四种知识来源选型；切块策略（决定检索成败的第一因素）；嵌入检索原理；50 行完整 RAG 管线；检索评估与四大失败模式诊断；知识库 × 记忆 × 本体的合流。📜 论文：RAG / GraphRAG。

⏱ 3 小时含实验：检索质量对比器

Agent 工程进阶

上下文压缩器；文件 / 向量 / 知识图谱三级记忆谱系；规划与反思（Reflexion）；多智能体编排完整代码；评估入门；安全防线。把「能跑的 demo」变成「可靠的系统」。

⏱ 3 小时6 段核心实现代码

深入理解 Ontology（本体）

从亚里士多德到知识图谱：类 / 实例 / 公理，RDF → RDFS → OWL → SPARQL 技术栈；rdflib 亲手建图与推理；LLM 抽取管线自动填充本体；本体在智能体中的三大用途；以 Palantir Ontology（对象·链接·动作）框架为主线并对比语义网路线。📜 经典：Gruber 1993 / Ontology 101。

⏱ 3 小时含实验：Ontology 实验室rdflib 实战

深入理解 Harness（智能体框架）

Harness 是模型之外的一切：八大组件解剖；mini-harness 升级实战；流式拼接、CostMeter、模型路由；「模型决定上限，Harness 决定下限」。📜 论文：SWE-agent（接口设计实证）。

⏱ 2.5 小时含实验：Harness 实验室

调试、评估与上线

五步定位法找根因；评估集三层结构与 LLM-as-Judge 代码；成本与延迟工程；CLI → Gradio → 服务化的上线路径与部署清单；上线后的改进飞轮；DeepSeek Harness 单文件参考实现，并对比 Pi Agent 等框架。

⏱ 2.5 小时含实验：Trace 侦探

综合实战：知识驱动的智能体（毕业项目）

四个里程碑的完整项目：本体 + 三元组记忆 → 本体化工具与 Harness → LLM 抽取管线 → 评估与 Web 界面。每个里程碑都有任务、验收标准、提示与参考实现——做完它，你就完成了从「学过」到「会做」的跨越。

随用随查

你需要哪些前置知识？

必需：基础编程

会 Python（或 JavaScript）的基本语法：函数、字典 / 对象、循环、异常、虚拟环境。不需要任何机器学习背景。

必需：会用终端

能打开终端、运行 pip install、设置环境变量。第 2 章开始会用到。

第 2 章起：一个 DeepSeek API Key

到 platform.deepseek.com 注册获取（几块钱能学完整门课）。没有 Key 也能学：所有交互实验都是纯前端模拟，代码照读不误。

不需要：数学 / 训练模型

本站教的是「应用层」智能体开发——调用大模型 API 而不是训练它。好奇心比数学更重要。

怎么用这个网站学？

  • 按流水线的顺序学，别跳。第 4 章（知识库）依赖第 3 章的结构化输出闭环；第 9 章总装前 8 章。跳章的代价在毕业项目会连本带利还回来。
  • 代码必须亲手跑。每段代码都标了文件名，建议建一个 agent-lab/ 目录跟着敲。跑不通的报错信息本身就是最好的教材。
  • 每章末尾的练习至少做一半。练习都配了参考答案（折叠在后面）——先自己写，写不出来再看，看懂后合上答案重写一遍。
  • 对照论文读。每章的「 论文精读入口」卡片指向对应的论文拆解——学完章节立刻读论文，是巩固最快的方式（三遍读法见论文页）。
  • 交互实验是思维模型。七个实验室都是「可操作的直觉」：先关掉开关看坏结果，再打开对比，比读十段文字更深刻。
  • 进度自动保存在浏览器里。每学完一章点「标记本章已学完」，下次接着来。
一条贯穿全站的主线

本站的所有内容都围绕一个公式展开：
Agent = LLM（五种角色的引擎）× Tools（手脚）× Knowledge（知识库·记忆·图谱）× Prompt（指令）× Harness（身体）× Ontology（共同语言）
第 1–3 章把引擎、手脚和指令接起来，第 4–5 章接入知识与记忆，第 6–7 章深入共同语言与身体，第 8 章保证质量，第 9 章总装交付。

学完你能做到什么

① 从零写出一个带工具调用、重试、流式输出的生产级 Agent 脚本；② 为你的业务设计并迭代系统提示词，用评估集验证效果；③ 搭建并诊断一套文档知识库，回答「检索不到」和「检索到了没读」两类问题；④ 用本体 / 知识图谱组织工具与记忆，实现多跳问答；⑤ 给 Agent 加上权限、成本核算与 Trace 调试；⑥ 把它变成可部署的 Web 应用，并用评估集做回归。每一条能力都对应具体章节与练习。
