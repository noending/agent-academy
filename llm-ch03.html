模型训练基础

本章目标：能够配置并启动LLM训练任务

训练环境搭建：GPU与分布式

要训练大语言模型，首先得把环境搭好。核心是GPU和分布式训练。单卡显存有限，模型大了就得用多卡甚至多机。

先检查你的GPU：

import torch
print(torch.cuda.is_available())
print(torch.cuda.device_count())
print(torch.cuda.get_device_name(0))

分布式训练常用数据并行（Data Parallelism），每个GPU持有完整模型副本，处理不同数据批次，梯度同步。PyTorch提供DistributedDataParallel（DDP）。启动方式：

# 单机多卡启动示例（命令行）
torchrun --nproc_per_node=4 train.py

在代码中初始化进程组：

import torch.distributed as dist
dist.init_process_group(backend='nccl')
local_rank = int(os.environ['LOCAL_RANK'])
torch.cuda.set_device(local_rank)
model = torch.nn.parallel.DistributedDataParallel(model, device_ids=[local_rank])

关键结论：分布式训练能线性提升吞吐，但要注意学习率随全局批次大小调整。

损失函数与优化器选择

语言模型训练通常用交叉熵损失（CrossEntropyLoss），预测下一个token。PyTorch中：

import torch.nn as nn
criterion = nn.CrossEntropyLoss(ignore_index=-100)  # 忽略padding

优化器首选AdamW，它修正了权重衰减，适合Transformer。学习率常用预热+余弦衰减。

from transformers import AdamW, get_cosine_schedule_with_warmup
optimizer = AdamW(model.parameters(), lr=5e-5, weight_decay=0.01)
scheduler = get_cosine_schedule_with_warmup(optimizer, num_warmup_steps=1000, num_training_steps=10000)

关键结论：损失函数选交叉熵，优化器选AdamW，学习率要预热。

训练循环与检查点保存

训练循环是核心，包括前向传播、计算损失、反向传播、优化器更新。每若干步保存检查点（Checkpoint），防止训练中断丢失进度。

model.train()
for epoch in range(epochs):
    for step, batch in enumerate(dataloader):
        inputs = batch['input_ids'].to(device)
        labels = batch['labels'].to(device)
        outputs = model(inputs, labels=labels)
        loss = outputs.loss
        loss.backward()
        optimizer.step()
        scheduler.step()
        optimizer.zero_grad()
        if step % 100 == 0:
            torch.save({
                'epoch': epoch,
                'model_state_dict': model.state_dict(),
                'optimizer_state_dict': optimizer.state_dict(),
                'loss': loss.item()
            }, f'checkpoint-{step}.pt')

关键结论：定期保存检查点，包含模型、优化器状态和当前步数。

常见训练问题与调试

训练中常遇到损失不下降、梯度爆炸、显存不足。调试方法：

  • 损失不降：检查学习率、数据标签、模型初始化。
  • 梯度爆炸：使用梯度裁剪torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)。
  • 显存不足：减小批次大小、使用梯度累积、混合精度训练。

混合精度训练示例：

from torch.cuda.amp import autocast, GradScaler
scaler = GradScaler()
with autocast():
    outputs = model(inputs, labels=labels)
    loss = outputs.loss
scaler.scale(loss).backward()
scaler.step(optimizer)
scaler.update()

关键结论：梯度裁剪和混合精度是稳定训练的利器。

常见误区

  • 学习率越大训练越快：过大的学习率会导致损失震荡甚至发散，需要预热和衰减。
  • 检查点只保存模型权重就够了：恢复训练还需要优化器状态、学习率调度器状态和当前步数。
  • 分布式训练一定比单卡快：如果通信开销大或批次太小，加速比可能很低，甚至变慢。

自测

为什么训练大语言模型通常使用AdamW而不是标准Adam？

答案：AdamW将权重衰减与梯度更新解耦，更适用于Transformer等模型，能防止过拟合且训练更稳定。

保存检查点时除了模型参数，还应该保存什么？

答案：还应保存优化器状态、学习率调度器状态、当前epoch和step，以便精确恢复训练。

动手练习（带参考方案）

动手练习 · 编写一个简单的训练循环，使用PyTorch训练一个线性回归模型，要求包含损失函数、优化器、每10步打…

任务：编写一个简单的训练循环，使用PyTorch训练一个线性回归模型，要求包含损失函数、优化器、每10步打印损失并保存检查点。

参考方案：

import torch import torch.nn as nn import torch.optim as optim # 数据 X = torch.randn(100, 1) y = 3 * X + 2 + 0.1 * torch.randn(100, 1) # 模型 model = nn.Linear(1, 1) criterion = nn.MSELoss() optimizer = optim.AdamW(model.parameters(), lr=0.01) for epoch in range(100): model.train() optimizer.zero_grad() outputs = model(X) loss = criterion(outputs, y) loss.backward() optimizer.step() if epoch % 10 == 0: print(f'Epoch {epoch}, Loss: {loss.item():.4f}') torch.save({ 'epoch': epoch, 'model_state_dict': model.state_dict(), 'optimizer_state_dict': optimizer.state_dict(), 'loss': loss.item() }, f'checkpoint-{epoch}.pt')
